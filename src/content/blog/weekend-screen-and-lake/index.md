有时候，一个舒服的周末不需要太长的计划。整理几段文字，关掉几个不再需要的标签页，再把目光移到窗外，就已经有了一点重新开始的感觉。

这篇小文放了两张很不一样的图片：一张来自博客项目本身，一张留在遥远的图片服务器上。前者像桌面上摆好的笔记本，后者像偶然翻到的一张明信片。

## 屏幕里，也可以留一点空白

![Minrock 模板的深色首页截图，展示简洁导航、大幅留白和文章列表](/images/theme-cover.png)

*本地图片：Minrock 模板演示截图，文件保存在本站的 `public/images/theme-cover.png`。*

这张截图里，最先让人注意到的并不是某个按钮，而是文字周围的空白。标题有自己的位置，段落之间保留了距离，文章列表也没有急着塞满整个屏幕。

写作大概也是这样。刚开始时，总想把所有背景都交代清楚，把每一个想法都装进同一段里。等到重读，才发现有些句子应该拆开，有些解释可以删去，还有些问题适合留到下一篇。

把一件事说清楚，往往比把很多件事写进去更难。一个个人博客的好处，是可以慢慢练习：今天写下观察，明天补上细节，过一阵再回来看看，当时的自己究竟在关心什么。

## 把视线交给远处

![山峰和针叶林环绕着蓝绿色湖泊，平静的水面映出山体与天空](https://images.unsplash.com/photo-1693051177382-c7025192175f?auto=format&fit=crop&w=1600&q=80)

*线上图片：摄影 [Mattia Poli / Unsplash](https://unsplash.com/photos/a-mountain-lake-surrounded-by-snow-covered-mountains-XPVVtqCQWzY)，图片通过外部地址加载。*

湖面的倒影把画面放慢了。山峰本来有很硬的轮廓，落进水里，就多了一层轻微的不确定；树林密密地站在岸边，却没有让人觉得拥挤。

看这样的照片，不一定是为了立刻安排一场旅行。有时只是提醒自己，世界的尺度比眼前的待办事项大得多。写到一半的句子可以稍后再改，尚未决定的事情也可以多想一天。

休息不必总有一个可展示的结果。散步时没有拍下好照片，读书时没有划出金句，下午没有完成原本设想的计划，也不妨碍它成为一个值得保留的下午。

## 留下一件很小的事

如果要给这个周末安排一个小任务，我想它应该足够简单：

- 写下今天真正注意到的一个细节。
- 把一张喜欢的图片放进文章，说明为什么喜欢它。
- 在准备继续刷屏之前，先站起来走一走。

等到下次打开博客，不需要看到一个完美的自己。看到曾经认真看过一张图片、写过几句话，就够了。

## 这两张图片怎么插入

本地图片已经放在项目的 `public/images/` 目录中。引用时省略 `public`，使用以 `/` 开头的网址路径：

```markdown
![Minrock 模板首页截图](/images/theme-cover.png)
```

线上图片直接使用完整的 HTTPS 地址：

```markdown
![山间湖泊与倒影](https://images.unsplash.com/photo-1693051177382-c7025192175f?auto=format&fit=crop&w=1600&q=80)
```

方括号里的文字是图片说明，在图片无法加载时也能传达内容。本地图片会随站点部署；线上图片需要读者能连接到对应的图片服务。两种方式都可以在同一篇 Markdown 文章中使用。
